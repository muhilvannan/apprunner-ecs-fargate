## Decisions Made

- `pathRewrite` strips `/workspace{id}/{appId}` prefix before forwarding — maintains parity with prior Envoy `prefix_rewrite: "/"` behaviour (D-05)
- Cloud Map cache keyed by `workspaceId` rather than `appId` — single DiscoverInstances call returns all apps for a workspace; fewer API calls than per-app caching
- Proxy middleware registered before hub GET routes in Express so app paths are intercepted correctly
- IAM `Resource: "*"` for DiscoverInstances — Cloud Map does not support resource-level restrictions for this action
