  <action>
Initialize Terraform directory structure (`terraform/`) with:

1. **main.tf** — Provider config for AWS (region from variable), locals for naming conventions, required_version constraints
   - Set provider default_tags { tags { Environment = var.environment, Project = "ecs-app-tester" } }
   - Create locals block: cluster_name = "ecs-app-tester-${var.environment}", namespace = "${local.cluster_name}.local"

2. **variables.tf** — Input variables:
   - `aws_region` (default: us-east-1)
   - `environment` (default: dev)
   - `cluster_name` (optional, uses local if not provided)
   - `vpc_cidr` (default: 10.0.0.0/16)
   - `availability_zones` (default: [us-east-1a, us-east-1b])
   - `container_log_retention_days` (default: 30)

3. **vpc.tf** — Complete VPC networking:
   - aws_vpc (CIDR: var.vpc_cidr, DNS hostnames enabled, DNS resolution enabled)
   - 2 public subnets (one per AZ, /24 subnetting)
   - 2 private subnets (one per AZ, /24 subnetting)
   - aws_internet_gateway (attach to VPC)
   - aws_eip for NAT Gateway (in public subnet)
   - aws_nat_gateway (in public subnet)
   - Route tables: public (0.0.0.0/0 → IGW), private (0.0.0.0/0 → NAT)
   - aws_security_group for ECS tasks (ingress: HTTP 80, HTTPS 443 from ALB; egress: all)
   - aws_security_group for ALB (ingress: HTTP 80, HTTPS 443 from 0.0.0.0/0; egress: all to ECS SG)

4. **outputs.tf** — Export for later phases:
   - vpc_id, vpc_cidr
   - public_subnet_ids (list), private_subnet_ids (list)
   - ecs_task_security_group_id
   - alb_security_group_id

5. **.gitignore** — Standard Terraform ignores:
   - .terraform/, .terraform.lock.hcl, *.tfstate*, *.tfvars (except .example), **/.env

6. **terraform.tfvars.example** — Document variable usage:
   - aws_region = "us-east-1"
   - environment = "dev"
   - vpc_cidr = "10.0.0.0/16"
   - availability_zones = ["us-east-1a", "us-east-1b"]
