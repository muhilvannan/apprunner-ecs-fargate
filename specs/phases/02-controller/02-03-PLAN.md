  <action>
Add endpoint:
- PUT /api/app/sync {workspaceId, appId, s3Bucket, s3Prefix}

Implement:
- List objects from S3 prefix (listObjectsV2)
- For each object, stream downloaded data to EFS path: /mnt/efs/workspace{workspaceId}/app{appId}/{objectKeyRelative}
- Validate EFS directory exists or create (fs.promises.mkdir recursive)
- Enforce that file writes cannot escape base path (security path normalization)
- Return summary (filesCopied, bytesCopied, errors)

Avoid copying large objects all in-memory (use pipeline/stream).

Expect 200 with details of transferred files.
  </verify>
  <done>

</done>
